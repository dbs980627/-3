왜 냉장고 파먹기인가요?

1인 가구·자취생은 장을 볼 때마다 "이미 있는 재료"를 까먹고 또 사거나, 애매하게 남은 재료를 결국 버리게 되는 경우가 많아요. 냉장고 파먹기는 지금 가진 재료만으로 오늘 먹을 한 끼를 빠르게 찾아주는 서비스예요.

🎯

목적

식재료 낭비를 줄이고, "뭐 먹지" 고민 시간을 줄이는 것.

🙋

타겟 사용자

자취생, 1인 가구, 요리 초보자, 장보기 전 냉장고를 정리하고 싶은 누구나.

⚡

핵심 가치

입력 후 몇 초 만에, 지금 있는 재료 기준으로 실제 만들 수 있는 레시피 제공.

기술 스택

HTML5 CSS3 Vanilla JavaScript Python 3 Vercel Serverless Functions Google Gemini API

자주 묻는 질문

재료를 정확한 양으로 입력해야 하나요?

아니요. "계란, 대파, 밥"처럼 이름만 나열해도 충분해요. 계량은 AI가 대략적인 기준으로 제안해요.

AI 응답이 실패하면 어떻게 되나요?

입력이 비어 있으면 즉시 안내 메시지가 뜨고, 서버·AI API 오류가 발생하면 오류 코드와 함께 다시 시도해달라는 메시지를 보여드려요. 응답이 20초 이상 지연되면 지연 안내 메시지로 전환돼요.

추천받은 레시피대로 재료가 꼭 다 있어야 하나요?

아니요. "있으면 더 좋은 재료"는 선택 항목으로 별도 표시돼요. 없어도 기본 레시피는 완성돼요.

어떤 AI 모델을 사용하나요?

Google Gemini API를 서버(Vercel Serverless Functions, Python)에서 호출해 레시피를 생성해요. API 키는 서버 환경 변수에만 저장되며 브라우저에는 노출되지 않아요.
